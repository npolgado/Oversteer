## Notes

### Long-term: Controller Support
Gamepad input would be a natural fit for a drift game. Priority: analog stick for steering, triggers for throttle/drift. Gamepad API is available in browsers — relatively low-lift to wire into `input.js`. Good candidate for a dedicated phase.

---

### HUD & In-game FX — visual polish needed
- **Speedometer** (`phase-3-spedometer.png`): "SPD" bar is functional but aesthetically rough — plain rectangle bar, low contrast, clashes with background.
- **Wall riding FX** (`phase-3-wall-riding.png`): cyan trail/sparks near border are visible but don't feel polished or intentional.
- Both are part of the broader asset + UI revamp needed across the game.

---

### UI Text — global readability issues
All screens affected: text is too small, stroke/outline weight too low, and some text is cut off at edges. Needs a global UI text pass — increase font sizes, add heavier outlines/shadows, and audit all text for clipping.

---

### Upgrade Card Icons — need overhaul
All upgrade card icons should be reviewed and replaced with proper symbols. Currently some are placeholder letters (e.g. Tight Turns = `R`). Part of the broader art/asset revamp.

---

### Balance: Mud slowdown too punishing
Mud slow is too severe — without a healing upgrade you can take repeated enemy hits while stuck recovering. Either reduce the slow magnitude or shorten the duration. Could also give the player a brief iframes window on entering mud to prevent instant pile-on.

---

### Long-known: Combo cap at 8x
Combo multiplier hard-caps at 8x. Acceptable for now but worth revisiting — higher cap (or no cap) could reward high-skill runs more meaningfully. Could also tie into upgrades or late-game difficulty scaling.

---

### Idea: Heading-Locked Camera Mode
Camera rotates so the car's heading always points "up" on screen, car stays centered.  
The world rotates around the player rather than the player moving through a fixed-orientation world.  
Could be a toggle or permanent mode — would make drift feel more immersive / racing-game-like.  
Risk: minimap, UI elements, and enemy direction indicators would all need to account for the world rotation offset.

---

### Wall Riding Border Range
Border range was widened for testing — needs to revert.  
Proposed: make it a percentage of world size rather than a hardcoded px value.  
e.g. 3000×3000 world → wall-riding zone = ~100px from edge (≈3.3% of world width).  
This scales cleanly if world size ever changes.

---

### Horde Banner — replace xN with repeated `!`
Current: `HORDE x6`  
Desired: `HORDE!!!!!!` — exclamation count = horde count, so it grows with each horde event.  
e.g. x1 → `HORDE!`, x6 → `HORDE!!!!!!`
