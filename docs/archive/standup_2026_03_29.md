## Testing Gaps

- **No TS tests yet for:** collision detection, wave system, scoring, HUD, upgrades, menus, screen FX, audio (these correspond to un-ported steps 6-13).
- **Legacy tests cover scoring, waves, pickups, upgrades, enemies, trail, utility** — good coverage of the original game logic. No tests for audio or FX (expected — hard to unit test).
- **game.js (1,773 lines)** is the largest file with no dedicated test file. It orchestrates everything. When porting, this should be broken into testable pieces.

## Suggested Priorities

1. **Continue Phase 1 step 6 (collision detection)** — this is the next logical step and unlocks waves/scoring.
2. **Clean up orphaned worktree branches** (`worktree-agent-*`) — minor housekeeping.
3. **Consider adding an integration-style test** that runs a simulated game tick through physics → player → trail → enemies to catch cross-system regressions early, before the full game loop is ported.

## Ideas for Future Consideration

- **Replay system** — record inputs per frame for deterministic replay. Useful for bug reports, leaderboard verification, and eventual multiplayer (deterministic sim is already called out as a prerequisite in the roadmap).
- **Automated visual regression** — screenshot the canvas at key frames and diff against baselines. Catches rendering bugs the unit tests miss.
- **Performance benchmark suite** — the Phase 2 roadmap calls for FPS benchmarking vs. vanilla JS. Setting up the benchmark harness now (even if Phase 2 is far off) would establish a baseline while both builds are fresh.
- **Documentation of the event bus contract** — as more systems subscribe to `eventBus`, documenting the event schema and who emits/listens will prevent coupling surprises.

## Overall Direction

The project is heading toward a Steam release through a structured 8-phase plan. The architecture migration is the current bottleneck — the original JS game is feature-complete at v1.0, and the TS/PixiJS port needs to reach parity before any new content or polish work can happen. The plan is solid and being executed in order. Stay focused on completing Phase 1 steps 6-13 before moving to visual polish (Phase 2).
